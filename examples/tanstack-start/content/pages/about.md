title: About
description: A demo blog built with Loomark, React 19 and Tailwind CSS 4.
---

Loomark is a small Markdown content library for React apps. This blog is the
example app: the posts live in `content/posts`, the schema lives in
`loomark.config.ts`, and everything else is generated.

The same content is rendered by a Next.js app and a React Router app, so the two
integrations can be compared side by side.
